Fish 16S Meta-analysis data package
Date: 2026-11-16

01_Metadata: metadata_full.tsv (2727 samples), metadata_rarefied_1000.tsv (2545 samples).
02_Abundance: non-rarefied and rarefied-1000 ASV tables in BIOM and QIIME2 formats.
03_Taxonomy_Sequences: taxonomy and representative sequences after eukaryota removal.
04_Microbial_Tree: SEPP microbial phylogenetic tree, placements and QIIME2 artifacts.
05_Diversity: Alpha diversity, Beta distance matrices, PCoA and NMDS results.
06_Function: FAPROTAX and Tax4Fun2 functional prediction results.
07_QC: quality-control reports.

SEPP tree matching: 35686/35686 rarefied ASVs matched (100%).
The microbial SEPP tree is not a fish host phylogenetic tree.
The metadata_full.tsv is matched to the 2727-sample functional prediction tables.
The metadata_rarefied_1000.tsv is for the 2545-sample rarefied diversity analysis.
